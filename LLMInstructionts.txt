
## 🧠 Copilot Instruction – Azure Function to Clean Up WAD Logs Across 8 Storage Accounts

**Context / Goal:**

I want to build an **Azure Function (Timer Trigger)** that deletes old WAD logs from Azure Table Storage across multiple storage accounts.
There are 8 different storage accounts, each containing several WAD tables such as `WADWindowsEventLogsTable`, `WADPerformanceCountersTable`, etc.
Each table contains diagnostic logs written by Windows VMs.

The function should:

* run on a **schedule (e.g. daily)**,
* connect to **multiple storage accounts**,
* delete rows older than a given retention period (e.g. 30 days),
* and log how many rows were deleted per account and table.

---

### ⚙️ Functional Requirements

1. **Trigger**

   * Use a **Timer Trigger**, scheduled via CRON (e.g. `0 0 3 * * *` for daily 3 AM UTC).

2. **Storage Accounts**

   * I have **8 connection strings**, stored in **Application Settings**:

     ```
     STORAGE_ACCOUNT_1
     STORAGE_ACCOUNT_2
     ...
     STORAGE_ACCOUNT_8
     ```
   * The function should loop through all connection strings.

3. **Tables**

   * Each storage account contains multiple tables starting with “WAD”.
     The function should enumerate all tables using the prefix filter (e.g. `WAD*`).

4. **Date Logic**

   * Each row has a `Timestamp` property (system property).
   * Delete all rows where `Timestamp` < `DateTime.UtcNow - retentionDays`.
   * The retention period (`retentionDays`) should be configurable via an environment variable.

5. **Deletion**

   * Use **batch delete operations** for efficiency (up to 100 entities per batch).
   * Handle continuation tokens to process large tables.
   * Log progress to Application Insights (account name, table name, rows deleted).

6. **Error Handling**

   * Continue processing remaining accounts/tables even if one fails.
   * Log failed deletions with exception details.

---

### 🧩 Implementation Notes

* Use **Azure.Data.Tables** SDK (`Azure.Data.Tables` NuGet package).
* Structure suggestion:

  * `CleanupTimer.cs` — main function.
  * `TableCleaner.cs` — helper class to handle connection, query, and delete logic.
* Use async/await for all Table operations.
* Write logs to both console and ILogger.

---

### 🧰 Configuration Example (local.settings.json)

```json
{
```
